预算只有几十块，能买到能用的 VPS 吗？能，但你得先知道便宜是怎么便宜下来的。这篇把 10 家商家的最低档 全部折算成月价横向排开，再讲清楚低价套餐省掉的四样东西——超售、线路、IP 质量、售后—— 以及一条我自己踩坑总结出来的底线：低于什么价位就别碰了。

「便宜 VPS」是个很容易翻车的需求。年付 $10 的机器确实存在，也确实能开机、能装系统、能跑起来， 但它和月付 ¥60 的机器之间隔着的不是配置，而是晚上八点还能不能用。 很多人第一次买 VPS 就是冲着便宜去的，用一周觉得挺好，第三周开始卡，第两个月发现 IP 被墙了， 找客服没人回——这时候年付的钱已经花了。

所以这篇不只是列便宜货。前半部分是横向价格表，后半部分是怎么判断这个便宜值不值得占。

便宜的代价：省掉的是哪四样东西

低价套餐不是商家做慈善，成本一定要从某个地方省出来。按影响从大到小排：

一、线路：最主要的差价来源

优质回程线路（CN2 GIA、AS9929、CMIN2）的带宽成本是普通国际线路的十倍以上， 这是低价机和优质机价差的主要构成。表现出来就是：

  • 白天很好，晚上很差：这是普通线路最典型的症状。凌晨测速能跑满，晚上 8–11 点掉到十分之一。
  • 测速跑得快，但打开网页很慢：带宽够但延迟高、丢包多。看视频还行，交互体验很差。
  • 时好时坏，没有规律：走的是拥堵的公共出口，取决于当时的路由情况。

所以只在白天测试就下单年付，是最常见的翻车方式。一定要在晚上 8 点之后测一次。

二、超售：低价档的默认玩法

一台物理机上开多少台 VPS，商家不会告诉你。低价套餐普遍超售严重，CPU、磁盘 I/O、网络都在抢。 判断方法：

  • 看 steal time：SSH 进去跑 top，看 CPU 行的 st 值。持续高于 5% 说明宿主机被抢得厉害。
  • 测磁盘 I/O：dd if=/dev/zero of=test bs=1M count=1024 oflag=direct， 正常 SSD 应该有 100MB/s 以上，只有几十 MB/s 说明磁盘被压得很厉害。
  • 不同时段各测一次：超售的机器性能波动会很明显。

对搭梯子来说超售的影响其实有限（代理软件本身不吃 CPU），但如果你还想跑建站、数据库、下载，就会很难受。

三、IP 质量：便宜机器最容易踩的坑

低价 IP 段被大量用户反复使用过，很可能已经被流媒体平台标记、被墙、或进了邮件黑名单。 买之前没法查，买之后要马上验：

  • 是不是已经被墙：国内 ping 不通但国外能通，说明 IP 已被墙。这种要立刻申请退款或换 IP。
  • 能不能解锁流媒体：如果你的用途包含看 Netflix、注册海外账号，数据中心 IP 大概率不行。
  • 有没有进黑名单：打算发邮件的话，IP 在垃圾邮件黑名单里就等于废了。

这也是为什么如果你的核心需求是「IP 要干净」，就不该在便宜档里挑—— 该去看 666Clouds 这类专门做原生 IP / 双 ISP 的商家，那是另一个价位的东西。

四、售后：出问题时才发现的差别

便宜商家的工单响应时间以天计，中文客服基本没有，换 IP 要收费甚至不提供。 平时感觉不到，IP 被墙那天就是全部的差别。买之前发一个售前工单试试响应速度，这个测试成本为零但很有用。

年付还是月付：这笔账怎么算

便宜 VPS 的低价几乎都绑定年付。年付通常能省 20%–40%，但你同时承担了商家跑路和机器不好用两个风险。 我的做法是分两步：

阶段 怎么做 为什么
第一个月 买月付，或买支持退款的套餐。晚高峰测三次，跑满一周 多花的钱是「测试费」，比年付打水漂便宜得多
确认好用后 转年付，但只对运营 3 年以上的商家这么做 新商家的年付相当于给一家没有信用记录的公司做无抵押贷款

有个例外值得一提：RackNerd 的促销价是永久锁定的，续费不涨价。 这类机制会让年付的性价比明显提高——因为你锁住的不只是这一年的价格。买之前确认这条政策还在。

不要买三年付、五年付。VPS 行业里三年是很长的时间， 省下的那点钱远远覆盖不了商家消失的概率。低价商家尤其如此。

底线：低于多少钱就别碰了

结合上面几条，给几个具体的判断标准，不用记，遇到时对一下就行：

情况 建议
折合月价 低于 ¥5 基本可以直接排除。这个价位覆盖不了正常的带宽和运维成本，要么严重超售，要么撑不了多久
折合月价 ¥5–15 可以买，但只用来做备用节点，别当主力。RackNerd 这一档属于这里
折合月价 ¥15–40 大多数人的合理区间。能买到 1Gbps 大流量，或者入门级优质线路
折合月价 ¥40 以上 开始能买到 CN2 GIA / AS9929 这类真正的优质线路，晚高峰体验有质变

再强调一次：「便宜」是相对于你的用途而言的。 只是挂个备用节点，¥8/月 就很够；如果这台机器你每天都要用好几个小时， 为了省 30 块钱天天忍受晚高峰卡顿，其实是笔亏本买卖。

怎么识别一家可能要跑路的商家

低价商家的跑路风险是真实存在的，年付尤其。下面这些信号出现两个以上，就别买年付了：

  • 价格明显低于同行且没有解释：别人 $20/年，它 $6/年，配置还更高——成本对不上就是有问题。
  • 只收加密货币：不支持支付宝、PayPal、信用卡这类可追溯、可申诉的支付方式，出事完全没有追索渠道。
  • 官网没有公司信息：没有注册主体、没有实际地址、whois 全隐私保护。
  • 域名注册不到一年：查一下 whois 的创建时间，新域名 + 超低价是典型组合。
  • 长期无限量促销：正规促销都有库存和时间限制，「永久 8 折不限量」是在冲现金流。
  • 社区完全搜不到：在 LowEndTalk、Hostloc 搜商家名，只有推广帖没有真实用户长期反馈。
  • 工单几天不回：售前都这样，售后只会更差。

降低风险最实际的办法不是挑到完美的商家，而是分散。 与其把一年的预算押在一家，不如在两三家各买一台低价机。 总价差不多，但任何一家出问题你都还有备用节点，切换成本几乎为零。

便宜VPS常见问题

最便宜的 VPS 大概多少钱？低于多少就不可信了？

目前正规商家的地板价大约在折合每月 ¥8–10（如 RackNerd 年付约 $13.76 的 1核1G 套餐）。

  • ¥5/月 以下：要非常警惕。带宽、IP、机柜、运维都是真实成本，这个价位很难覆盖，通常意味着极端超售或短期圈钱。
  • 注意计费周期：很多「$1.5/月」的宣传实际是三年付折算，一次性要付 $54，风险完全不同。
  • 注意配置缩水：512MB 内存、10GB 硬盘、500GB 流量的机器，很多用途根本跑不起来，便宜没有意义。
便宜 VPS 能用来搭梯子吗？会不会很卡？

能用，但体验取决于线路而不是价格本身。

  • 配置完全够：搭梯子对 CPU 内存要求极低，1核512M 都跑得动主流协议。
  • 线路是关键：便宜机大多走普通国际线路，白天没问题，晚上 8–11 点会明显掉速。
  • 折中方案：预算提到 $5.50/月 左右可以上 ByteVirt 的 CN2 GIA / AS9929，晚高峰稳定性有质的差别。
  • 务实做法：便宜机当备用，主力节点买优质线路。两台加起来也就 ¥50/月 左右。
为什么同样是 1核1G，价格能差 5 倍？

因为 CPU 和内存是 VPS 成本里最便宜的部分，真正贵的是别的东西：

  • 回程线路：CN2 GIA、AS9929 的带宽成本是普通国际线路的十倍以上，这是主要差价。
  • IP 质量：原生 IP、双 ISP 住宅 IP 的获取成本远高于普通数据中心 IP。
  • 超售比例：同样的物理机，塞 20 个用户和塞 100 个用户，单台成本差 5 倍。
  • 机房位置：香港、日本的机柜和带宽成本远高于美国。

所以比价时要连着线路、流量、IP 类型一起比，只看「几核几G」必然得出错误结论。

便宜 VPS 的年付值得买吗？会不会跑路？

风险真实存在，但可以管理：

  • 先月付试一个月，确认晚高峰能用、IP 没被墙，再考虑年付。这一个月的差价是最值的保险。
  • 只对老商家买年付：运营 3 年以上、社区有长期真实反馈的，跑路概率显著低。
  • 别买三年付、五年付：省的钱覆盖不了商家消失的概率。
  • 用可追溯的支付方式：支付宝、PayPal、信用卡出问题还能申诉，只收加密货币的要格外谨慎。
  • 分散下单：同样的预算分到两三家，比押在一家安全得多。
买了便宜 VPS，第一件事该做什么？

在退款窗口关闭之前，把这几项测完：

  • 查 IP 是否被墙：国内 ping 不通、国外能通 = 已被墙，立刻申请退款或换 IP。
  • 晚高峰实测：晚上 8–11 点测一次速度，这是唯一有意义的测试时段。
  • 看回程路由：确认线路是不是和宣传一致，走没走优质回程。
  • 查 steal time：top 里 CPU 行的 st 值持续高于 5%，说明超售严重。
  • 测磁盘 I/O：dd if=/dev/zero of=test bs=1M count=1024 oflag=direct，低于 100MB/s 要注意。
  • 发个工单：随便问个问题，看响应速度，这就是你以后的售后体验。
Vultr 关机了还会不会收费？

会。这是 Vultr 最容易让人吃亏的一点。

  • Vultr 按小时计费的是实例的存在，不是运行状态。关机（Stop）后实例仍然占用 IP 和存储资源，照常计费。
  • 要真正停止计费，必须销毁（Destroy）实例。
  • 如果想保留数据又不想付全价，可以先做快照（Snapshot）再销毁实例，快照单独按容量计费，便宜很多。
  • 另外注意 $2.50 那档只有 IPv6，没有 IPv4，很多场景用不了。
便宜 VPS 能解锁 Netflix、注册海外账号吗？

大概率不行，这是便宜机最明显的短板。

  • IP 类型不对：便宜机基本都是数据中心 IP，流媒体平台会直接识别并拦截。
  • IP 已被用脏：低价 IP 段被反复使用，很多已被平台标记。
  • 解决方案不在这个价位：需要原生 IP 或双 ISP 住宅 IP， 要看 666Clouds（¥45/月 起，七地区原生 IP）或 丽萨主机（¥68/月 起，全流媒体解锁）这类专门做 IP 质量的商家。

结论：如果核心需求是 IP 干净，就不该在便宜档里挑，省下的钱会以反复换机器的形式还回去。

便宜 VPS 适合建站吗？

看是什么站、给谁看：

  • 个人博客、练手项目：完全够。1核1G 跑 WordPress 没问题，RackNerd 3核3G 那档甚至能跑得挺舒服。
  • 面向国内访客：不建议。普通线路国内访问慢，直接影响跳出率。
  • 面向海外访客：可以。美国机房访问欧美本来就快，线路对国内的优化与否不影响海外用户。
  • 商业站点：不建议。便宜机没有可用性保证，宕机、跑路的损失远超省下的服务器费。
  • 注意硬盘和 I/O：建站比搭梯子更吃磁盘，优先选 NVMe 和容量大一些的档位。
RackNerd 的「永久锁价」是真的吗？

这是 RackNerd 长期主打的政策：促销价买入后，续费维持原价不上调。

  • 实际意义：低价机的常见套路是首年便宜、次年恢复原价，锁价政策规避了这一点，长期持有的性价比明显更高。
  • 前提是别断：一旦退订或过期释放，再买就要按当时的价格，原来的锁定价拿不回来。
  • 下单前确认：政策可能调整，购买页面和工单确认一下当前是否仍然适用。
同样的预算，是买一台好的还是几台便宜的？

取决于你怕的是什么：

  • 怕卡：买一台好的。三台普通线路的机器晚高峰会一起卡，数量解决不了线路问题。
  • 怕断：买几台便宜的，分散在不同商家。任何一台 IP 被墙或商家出问题，切换成本几乎为零。
  • 推荐组合：一台优质线路当主力（¥40–60/月），一台低价机当备用（¥10/月 左右）， 总共 ¥50–70/月，既有体验也有冗余。

纯粹堆数量的便宜机不解决体验问题，纯粹单点的好机器不解决可用性问题。
